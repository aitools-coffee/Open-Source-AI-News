## Contributing

Contributions are welcome! Please read the [contribution guidelines](CONTRIBUTING.md) first.

If you know of an AI newsletter that should be on this list, please open an issue or submit a pull request.

### Criteria for Inclusion

- The newsletter must be **actively published** (updated within the last 3 months)
- It must provide **original curation or analysis** (not just auto-generated feeds)
- It should be **free to subscribe** (premium tiers are fine, but a free option must exist)
- No spam, affiliate-only, or purely promotional newsletters
