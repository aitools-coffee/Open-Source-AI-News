# Contributing to Open Source AI News

Thank you for your interest in contributing! This list is community-driven, and we welcome additions, corrections, and improvements.

## How to Contribute

### Adding a Newsletter

1. Fork this repository
2. Add your newsletter to the appropriate category in `README.md`
3. Follow the existing table format:
   ```
   | [Newsletter Name](https://url.com) | Brief description of what makes this newsletter valuable. |
   ```
4. Submit a pull request with a clear description

### Guidelines

- **Alphabetical order** is not required &mdash; newsletters are roughly ordered by relevance within each category
- **Descriptions** should be concise (one sentence) and highlight what makes the newsletter unique
- **URLs** should point to the subscription or homepage &mdash; no referral links or tracking parameters
- **Categories** &mdash; if your newsletter doesn't fit an existing category, propose a new one in your PR description

### Quality Standards

Before submitting, ensure the newsletter:

- [ ] Has been actively publishing for at least 3 months
- [ ] Has a free subscription tier
- [ ] Provides original curation or analysis (not just RSS aggregation)
- [ ] Is focused on AI, ML, data science, or related topics
- [ ] Does not exist in the list already

### Removing a Newsletter

If a newsletter has stopped publishing, changed focus, or become spam, please open an issue with evidence and we'll review it.

## Code of Conduct

Be respectful. This is a community resource. We're all here to help each other stay informed about AI.
